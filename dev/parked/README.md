# 보류 모듈 (앱에 배선되지 않음)

여기 있는 파일은 **앱에서 import 되지 않고 sw.js 프리캐시에도 없다.** 되살릴 때 배선부터 확인할 것.

## v1.0 전면 개편(2026-09-29, S1)으로 내려온 것 — 내부 5팀 구조

사장님 확정: 상대는 **외부 클럽만**. 내부 팀 배정(A~F)·팀 묶음 제안·팀별 감독 평가는 v1.0에서 제거했다.
데이터는 사라지지 않는다 — 올릴 때 `woosulsan-fc:backup-v0.7` 키에 옛 저장값을 통째로 남기고, 설정에서 내려받기·복원이 된다.

- `balance.js` — 참석자 전력 균형 배분(`balanceTeams`) + 고정 팀 묶음 제안(`suggestMerges`) + 팀 수 추천.
  S3(전술보드 라인업)에서 "포지션 슬롯 배정"이 필요해지면 균형 계산부만 참고할 수 있다.
- `tactics-v0.x.js` — v0.x 전술판(경기별 핀·포메이션). S3에서 **상대 포메이션 겹치기**까지 들어간
  새 전술보드 엔진으로 다시 만든다. 필드 SVG·드래그 처리 방식은 여기서 가져올 만하다.
- `team-tab-v0.7.js` — v0.7 팀 탭 화면 전체(팀 카드·묶음 제안·선발/교체 이동·PNG 내보내기·팀 이름 설정·감독 평가 화면).
  화면 구조는 폐기지만 PNG 내보내기(`exportTeamsPNG`)와 능력치 요약표는 S3~S4에서 재활용 후보.
- `test-teams-v0.7.mjs` — 위 구조를 검증했던 테스트. v1.0 검증은 `dev/test-migrate.mjs` 로 대체.

## v0.6 — 상대 클럽 링크 공유 (2026-09-22 보류)

- `share.js` — 공유 카드 v1 포맷: JSON → deflate(가능 시) → base64url → `#t=<payload>` 링크,
  `buildTeamCard()` 는 기본적으로 이름·포지션·등번호만 싣고 실력/나이/성별/능력치는 옵션.
- `lineup.js` — 대외 경기 선발팀: GK 확보 → 포메이션 슬롯을 선호 포지션 + 종합 실력(+능력치 보조:
  수비 슬롯 defense·physical / 공격 슬롯 speed·shoot / 중원 basic·stamina)으로 그리디 배정 → 나머지 벤치(실력순).
  `recordOf()` 는 대외 전적(승무패·최근 5경기) 계산.

S2(상대팀 카드)·S3(전술보드)에서 `lineup.js` 의 슬롯 배정과 `recordOf()` 는 그대로 쓸 수 있다.
